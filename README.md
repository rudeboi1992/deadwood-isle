**US East · PvP · 50 slots · Islands map** · 2.5x loot, 2x vehicles and harvest, indestructible plated bases.

## Join

In the in-game server browser, search for **Deadwood** (listed as `NEW|US-East|Deadwood|2x Loot/Veh/Harvest|Indestructible Plated`). Steam downloads the three Workshop mods when you join: [Admin Chat Commands](https://steamcommunity.com/sharedfiles/filedetails/?id=2217434939), [BMW M4 & Charger Interceptor](https://steamcommunity.com/sharedfiles/filedetails/?id=2005194385) and [Deadwood Isle – Base Limits](https://steamcommunity.com/sharedfiles/filedetails/?id=3797893300).

## Rules

1. No cheating, exploiting or glitching through bases.
2. No hate speech in chat. Trash talk is fine; slurs get you banned.
3. Don't build inside or block spawn points, roads or loot buildings.
4. Admin decisions are final. Admins don't play favorites and don't spawn gear for anyone in normal play.
